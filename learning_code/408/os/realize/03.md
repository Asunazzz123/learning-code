```
semaphore mutex = 1 // 生产者消费者互斥
semaphore size = N  // 缓冲区容量
semaphore red = 0   // 缓冲区内红件个数
semaphore blue = 0  // 缓冲区内蓝件个数

producer(){
    while(true){
        P(mutex); // 进入缓冲区
        P(size);
        color = produce();
        if (color == red) V(red); // 放入红件
        if (color == blue) V(blue); // 放入蓝件
        V(mutex); // 离开缓冲区
    }
}

redConsumer(){
    while(true){
        P(red);   // 减少红件个数
        P(mutex); // 互斥进入缓冲区
        get_red();// 获得红件
        V(size);  // 释放缓冲区容量占用
        V(mutex); // 退出加工区
        process_red();
    }
}


blueConsumer(){
    while(true){
        P(blue);  // 减少蓝件个数
        P(mutex); // 互斥进入缓冲区
        get_blue();// 获得蓝件
        V(size);  // 释放缓冲区容量占用
        V(mutex); // 退出加工区
        process_blue();
    }
}


```

2. 缓冲区非空时，对应的颜色工件可能没在缓冲区内，进程可能错误进入缓冲区忙等待，如果没有对应颜色工件的消费者线程进入临界区可能导致死锁
3. 消费者先获得缓冲区，此时如果没有对应颜色的工件且消费者始终占用缓冲区，生产者无法进入缓冲区产生相应的工件以死锁


## 修正

生产者也需要先生产后放入临界区，避免缓冲区满的忙等待死锁
```
producer(){
    while(true){
        item = produce();
        P(size);
        P(mutex);
        put(item);
        if(is_red(item)) V(red);
        else V(blue);
        V(mutex);
    }
}
```
