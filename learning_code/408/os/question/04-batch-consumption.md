# 04 批量取件：消费者的连续访问权

参考 2014 年 T47 的批量消费模型改编。建议用时 18 分钟；练习分值 12 分。

## 题目

多个生产者和多个消费者共享容量为 N 的环形缓冲区，初始为空，N≥1。每个生产者反复生产并放入一件产品。

每个消费者一旦开始一个批次，就必须连续取走 K 件产品，K≥1。在这个批次结束前，其他消费者不能取件，但生产者仍可放入产品。

“连续”只约束消费者之间的批次不能交错，不要求 K 件在同一时刻都已备齐。一个批次可以因产品不足暂停，等生产者补充后继续。因此允许 K>N。

消费者取完一个批次后，在缓冲区外处理这一批产品；处理动作不属于批次取件的独占区间。假定生产者会持续生产。

## 作答要求

1. 列出信号量及初值，用 PV 伪代码描述生产者、消费者。（7 分）
2. 分别指出“一个批次由谁取件”和“某一次缓冲区访问”需要保护什么。（2 分）
3. 分析 N=2、K=3 时，你的方案如何完成一个批次。（1 分）
4. 若消费者持有缓冲区互斥权不放，在其中等待并取完 K 件，给出可能死锁的调度。（2 分）

不得把 K 次取件简写为不存在的 P(full,K) 原子操作；普通 P 每次只申请一个单位。无须实现环形数组，直接写“放入一件”“取走一件”。

## 检查场景

- 消费者 C1 已取 1 件而缓冲区为空，生产者能否补货？
- C1 未取满 K 件前，C2 能否抢走新放入的产品？
- C1 处理整批产品时，C2 能否开始下一批次？

仅提交 PV 伪代码和文字说明，不写 C++。
