# 01 展馆容量与唯一通道

参考 2013 年 T45 的容量限制与出入口互斥模型改编。建议用时 10 分钟；练习分值 8 分。

## 题目

某展馆最多允许 C 人同时参观，C≥1。展馆只有一条双向通道，任意时刻最多允许一人通过，不允许进出两人同时使用。初始展馆为空。

参观者在展馆外等待，获得入馆资格后通过通道进入，参观结束后通过同一通道离开。多个参观者可以同时参观。

每位参观者的业务顺序固定为：

```text
参观者 i：
    通过通道进入
    参观
    通过通道离开
```

## 作答要求

1. 列出信号量的含义和初值，用 PV 伪代码写出参观者进程。（5 分）
2. 说明如何保证容量限制与通道互斥，为什么“参观”不能全程占有通道。（1 分）
3. 若入馆者先占用通道，再等待容量名额，分析展馆已满时可能发生的死锁。（2 分）

容量名额应在入馆前申请；已申请但尚未进入的人可以暂时占用一个名额，任何时刻实际在馆人数不得超过 C。离馆时，应在通过通道之后归还名额。

## 检查场景

- C=1，一人在馆内，另一人等待入馆，此时馆内人员能否离开？
- 馆内尚有空位时，是否允许多名已入馆者同时参观？
- 入馆者等待名额时是否妨碍别人出馆？

仅提交 PV 伪代码和文字说明，不写 C++。
