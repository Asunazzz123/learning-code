# 05 双信箱：非空初始状态与双向协作

参考 2015 年 T45 的双信箱模型改编。建议用时 15 分钟；练习分值 10 分。

## 题目

A、B 两个进程通过各自的信箱交换问题和答复：

- A 的信箱容量为 M，初始有 x 封邮件。
- B 的信箱容量为 N，初始有 y 封邮件。
- 本练习规定 M,N≥2，1≤x<M，1≤y<N。
- A 只能从 A 信箱取邮件，回答后将一封新邮件放入 B 信箱。
- B 只能从 B 信箱取邮件，回答后将一封新邮件放入 A 信箱。
- 信箱空时不能取，满时不能放。
- 同一个信箱的取出与放入动作必须互斥，但两个信箱可以同时被操作。

每个进程的业务顺序固定为：

```text
反复执行：
    从自己的信箱取出一封邮件
    回答问题并生成一封新邮件
    将新邮件放入对方信箱
```

## 作答要求

1. 为两个信箱分别声明信号量及初值，写出 A、B 的 PV 伪代码。（6 分）
2. 指出哪些初值需要依据 x、y 计算，不能机械地将所有“有邮件”信号量设为 0。（1 分）
3. 说明为什么回答问题时不应持有信箱互斥权，为什么不应跨越两个信箱的等待一直持锁。（1 分）
4. 额外讨论：若改成 x=y=0，两个进程会怎样？这是否说明原有同步方案一定写错？（2 分）

本题初始邮件数的范围为练习自行规定。不要从本题反推原题 OCR 缺损处的准确措辞。

## 检查场景

- M=3、N=2、x=2、y=1，逐步跟踪一次双方取信与投信。
- A 正在等待 B 信箱出现空位时，B 能否取走自己的邮件？
- 一个信箱的操作是否会无必要地阻止另一信箱的独立操作？

仅提交 PV 伪代码和文字说明，不写 C++。
