# 02 汇合与分叉：任务前驱关系

参考 2020 年 T45、2022 年 T46 的前驱约束模型改编。建议用时 12 分钟；练习分值 10 分。

## 题目

六个操作 A、B、C、D、E、F 各执行一次，满足下列全部约束：

- A、B 均完成后，C 才能开始。
- C 完成后，D 和 E 才能分别开始。
- D、E 均完成后，F 才能开始。

四个并发线程负责的操作及线程内顺序固定为：

```text
T1：A；D
T2：B；E
T3：C
T4：F
```

A 与 B、D 与 E 应允许并发。除上述前驱关系和线程内顺序外，不增加额外先后约束。

## 作答要求

1. 列出信号量含义与初值，在四个线程中插入 P、V 操作。（6 分）
2. 说明哪些约束已由线程内顺序保证，哪些必须通过线程间同步实现。（2 分）
3. 若有人在 C 完成后只执行一次 V(doneC)，却让 D、E 分别执行一次 P(doneC)，是否正确？给出执行过程说明。（2 分）

不要求信号量数量最少。这里每个操作只执行一次，不需要设计重复轮次的屏障。

## 检查场景

- A 很快完成而 B 尚未完成时，C 能否提前执行？
- C 完成后，D、E 是否都能获得开始机会？
- D 完成而 E 尚未完成时，F 是否仍会等待？

仅提交 PV 伪代码和文字说明，不写 C++。
