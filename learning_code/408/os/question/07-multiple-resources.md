# 07 多资源联合申请：相邻工具与共享托盘

参考 2019 年 T43 的“筷子＋碗”资源模型改编。建议用时 20 分钟；练习分值 12 分。

## 题目

n 名工人围成一圈，n≥3，编号 0..n-1。工具也有 n 件，工人 i 需要工具 i 与工具 (i+1) mod n。另有 m 个可互换的托盘，m≥1。

每个工人反复执行准备、加工、休息。开始加工前必须获得自己的两件工具及一个托盘；加工结束后归还全部资源。

工具和托盘均只能由一个工人占用。相邻工人不能同时加工，但不冲突的工人应有机会并行加工，不得用一个全局互斥量将所有人的完整加工过程串行化。

## 作答要求

1. 用信号量或信号量数组表示资源，列出含义与初值。（2 分）
2. 用 PV 伪代码写出工人 i 的活动，确保不会出现死锁。（6 分）
3. 说明避免死锁的依据：消除了循环等待，还是采用了其他可证明的策略。（2 分）
4. 推导由工具与托盘数量共同决定的同时加工人数上限；讨论你的方案是否允许达到该上限的执行安排。（2 分）

可以自行选择申请策略，不要求证明每时每刻都实现最大并发，也不要求无饥饿。不能假设“同时申请三种资源”是一个现成原子操作；只允许普通单次 P、V。

## 检查场景

- m=1 时是否仍可能形成工具资源的循环等待？
- m≥n 时，是否仅凭托盘数量足够就可以保证无死锁？
- n=5、m=2 时，是否存在两名工人同时加工的安排？
- 工人申请某件工具时被阻塞，已占有的其他资源会形成什么等待关系？

仅提交 PV 伪代码和文字说明，不写 C++。
