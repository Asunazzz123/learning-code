# 02 BST 剪枝：升序输出范围内的键

进阶题。

给定严格 BST（键互不相同）与整数 low≤high，升序输出所有位于闭区间 [low,high] 的键，允许空树。

```cpp
void printRange(TreeNode *root, int low, int high);
```

## 要求

- 利用 BST 性质剪去不可能含有答案的子树。
- 不将整棵树先复制到数组，不排序。
- 说明当前键低于 low、高于 high、位于范围内时分别应访问哪些子树。
- 设输出键数为 r，分析 O(h+r) 时间和 O(h) 递归栈空间。
- 输出为空时不输出任何键。

## 自测

将键 4、2、6、1、3、5、7 按此顺序插入 BST：

- [3,6]：3 4 5 6。
- [8,10]：无输出。
- [4,4]：4。
- 空树：无输出。
