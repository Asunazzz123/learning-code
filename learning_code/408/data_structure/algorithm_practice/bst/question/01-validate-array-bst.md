# 01 顺序存储：判断是否为 BST

关联方法：2022 年真题；基础题。

二叉树以数组存储，根下标为 0，左右孩子下标为 2i+1、2i+2。不存在的结点用 -1 表示，实际结点值均为正整数。输入保证结构合法：不存在有效结点的祖先为空的情况。

采用严格 BST 定义：左子树所有值小于根，右子树所有值大于根，不允许重复键。数组长度 n 可以为 0。

```cpp
bool isBST(const int T[], int n);
```

## 要求

- 时间 O(n)，辅助空间 O(h)，h 为树高；不改变数组。
- 任选中序状态检查或上下界传递实现。
- 终止条件同时考虑下标越界与空结点标记。
- 使用安全的下标和界限表示，避免边界计算溢出。
- 构造例子解释仅比较父结点与直接孩子为何不充分。

## 自测

- [4,2,6,1,3,5,7]：true。
- [4,2,6,-1,5]：false，5 虽大于父结点 2，却仍在根 4 的左子树。
- [2,2,3]：false。
- []：true。
