# 03 BST 查找路径：最接近 K 的所有键

关联方法：2026 年本地回忆整理题；进阶题。

给定非空严格 BST，查找使 |key-K| 最小的所有键，输出最小差值及所有达到该差值的键；键按升序输出。键互不相同，最多有两个不同键并列最优。

```cpp
void printClosest(TreeNode *root, int K);
```

## 要求

- 时间 O(h)，辅助空间 O(1)，使用迭代，不遍历整棵树。
- 沿 BST 查找路径维护必要候选，解释为何其他子树不会给出更好的答案。
- 必须处理前驱与后继同时达到最小差值的情况。
- 精确命中时正确处理。
- 差值用足够宽的类型计算，不能先做 int 减法再取绝对值。
- 输出格式：第一行最小差值，第二行所有最优键。

## 自测

将 8、4、12、2、6、10、14 按此顺序插入 BST：

| K | 差值 | 最优键 |
|---:|---:|---|
| 5 | 1 | 4 6 |
| 8 | 0 | 8 |
| 1 | 1 | 2 |
| 20 | 6 | 14 |

另测退化成单支链的 BST；分析此时 h 与结点数的关系。
