# 01 候选抵消：寻找主元素

关联方法：2013 年真题；基础题。

给定非空数组，若某个值出现次数严格大于 n/2，称它为主元素。值可为任意 int；存在时通过 answer 返回它，并返回 true，否则返回 false。

```cpp
bool majorityElement(const int A[], int n, int &answer);
```

## 要求

- 时间 O(n)，辅助空间 O(1)，不排序、不使用频次数组。
- 第一遍筛选候选，第二遍检查真实出现次数。
- 说明不同值成对抵消为何不会排除真正的主元素。
- 说明第一遍留下候选为何不能直接证明它是主元素。
- answer 在返回 false 时内容不限。

## 自测

[5,1,5,2,5] → true，answer=5；[1,2,3] → false；[1,1,2,2] → false；[-1] → true，answer=-1。
