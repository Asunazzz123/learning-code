# 02 后缀极值：每个位置的最大乘积

关联方法：2025 年本地回忆整理题；进阶题。

对每个位置 i，求 res[i]=max(A[i]*A[j])，其中 i≤j<n。允许取 j=i，数组元素可正、可负、可为零。

```cpp
void suffixMaxProduct(const int A[], long long res[], int n);
```

## 要求

- 时间 O(n)，除输出外辅助空间 O(1)。
- 不改变 A；A 与 res 不重叠；允许 n=0。
- 说明仅维护后缀最大值为什么不够。
- 明确计算 res[i] 时，极值对应的后缀是否包含 A[i]。
- 乘法使用 long long，避免 int 乘法先溢出。

## 自测

- [1,4,-9,6] → [6,24,81,36]。
- [-2,-3] → [6,9]。
- [0,-2,3] → [0,4,9]。
- [-5] → [25]。
- 空数组不写入任何结果。
