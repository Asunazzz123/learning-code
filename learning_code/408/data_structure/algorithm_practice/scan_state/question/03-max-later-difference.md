# 03 前缀状态：后项减前项的最大值

基础题。

给定长度 n≥2 的数组，求 max(A[j]-A[i])，约束为 0≤i<j<n。必须选两个不同位置，即使所有可选差值都为负，也不能用 0 代替答案。

```cpp
long long maxLaterDifference(const int A[], int n);
```

## 要求

- 时间 O(n)，辅助空间 O(1)，不修改输入。
- 解释扫描到 j 时，需要记住前面哪些信息。
- 明确先更新答案还是先把 A[j] 纳入历史状态，并依据 i<j 解释。
- 使用足够宽的类型计算差值。

## 自测

- [7,1,5,3,6,4] → 5。
- [5,4,2] → -1。
- [3,3] → 0。
- [-4,-8,-1] → 7。
