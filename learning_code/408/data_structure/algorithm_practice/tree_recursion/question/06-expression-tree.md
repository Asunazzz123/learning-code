# 06 表达式树与括号输出

本题沿用 2017 年第 41 题的表达式树背景，练习递归中的位置参数和输出时机。

```cpp
struct ExprNode {
    char data[10];
    ExprNode *left;
    ExprNode *right;
};
```

约定输入是合法表达式树：

- 叶子保存操作数，可以是多字符，如 `abc`、`123`。
- 二元运算符为 `+`、`-`、`*`、`/`，均有左右孩子。
- 一元负号保存为 `-`，只有右孩子。
- 空树不输出任何字符。

## 输出规则

按中序输出表达式，每个非根的非叶子结点所对应的完整子表达式，外面加一对括号。根对应的整个表达式不加最外层括号，叶子不加括号。无需进一步消除冗余括号。

## 要求

1. 实现 `printExpr(ExprNode *root)`。
2. 第一版辅助函数通过 `depth` 判断当前结点是否为根，根深度为 1。
3. 第二版改用 `bool isRoot`，其他规则相同。
4. 解释左括号为什么应在递归左子树之前输出，右括号为什么应在递归右子树之后输出。
5. 说明为什么仅用“有无孩子”不能区分根运算符和内部运算符。

## 自测

| 树的含义与结构 | 期望输出 |
|---|---|
| 单个操作数 `abc` | `abc` |
| 根为 `+`，左右叶子为 `a`、`b` | `a+b` |
| 根为 `*`，左子树为 `a+b`，右子树为 `c-d` | `(a+b)*(c-d)` |
| 根为一元负号，右子树为 `a+b` | `-(a+b)` |
| 根为 `+`，左叶子为 `a`，右子树为一元负号 `-b` | `a+(-b)` |
| 根为 `/`，左叶子为 `a`，右子树为 `b/c` | `a/(b/c)` |

最后一例需要保留右子树的括号，以保持原树表示的运算次序。
