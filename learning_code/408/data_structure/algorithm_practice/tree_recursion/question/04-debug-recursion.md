# 04 递归调试：空指针与单孩子结点

下面的程序试图统计二叉树的叶子数，但存在错误：

```cpp
int countLeaves(Node *p) {
    if (p == nullptr) {
        std::cout << "empty";
    }
    if (p->left == nullptr || p->right == nullptr) {
        return 1;
    }
    countLeaves(p->left);
    countLeaves(p->right);
    return 0;
}
```

## 要求

1. 找出空指针处理、叶子判断和递归返回值使用方面的问题，并解释后果。
2. 修正程序，函数只返回叶子数，不输出调试信息。
3. 分别跟踪空树、单结点树、根只有左孩子、根有两个叶子孩子这四种情况。
4. 对“叶子判断中的逻辑运算符错误”，给出一个能单独暴露它的最小非空树例子。
5. 说明：递归调用得到的返回值被丢弃，与递归调用没有执行，是不是同一回事？
