# 01 遍历顺序与递归执行过程

给定二叉树：

```text
        1
       / \
      2   3
       \ / \
        4 5 6
```

其中 2 只有右孩子 4，3 的左右孩子分别为 5、6。

## 要求

1. 分别手写先序、中序、后序遍历序列。
2. 实现三个递归函数：`preorder`、`inorder`、`postorder`。
3. 对中序遍历，跟踪从进入结点 1 到输出结点 2 的过程。记录函数调用、空指针返回和输出事件。
4. 说明：为什么中序遍历中，进入某个结点的函数调用时，不一定立即输出它？
5. 分析空树和只有一个结点时，三个函数分别执行什么操作。

## 接口

```cpp
void preorder(Node *root);
void inorder(Node *root);
void postorder(Node *root);
```
