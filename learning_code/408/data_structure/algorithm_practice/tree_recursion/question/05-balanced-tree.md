# 05 后序递归：判断平衡二叉树

如果一棵二叉树中，每个结点的左右子树高度之差的绝对值都不超过 1，则称它为高度平衡的二叉树。空树也视为平衡。

注意：本题不要求它满足二叉排序树的大小关系。

## 要求

1. 设计递归算法判断给定二叉树是否平衡。
2. 时间复杂度要求为 O(n)，不得对同一子树反复独立计算高度。
3. 自行设计辅助函数，使一次递归既能提供判断平衡所需的信息，又能提供父结点需要的高度信息。
4. 解释为什么判断当前结点前，需要先得到左右子树的处理结果。
5. 分析最坏情况下的递归栈空间。

## 接口

```cpp
bool isBalanced(Node *root);
```

## 自测

- 空树：平衡。
- 单结点树：平衡。
- 根只有一个叶子孩子：平衡。
- 三个结点构成的单支树：不平衡。
- 构造一棵根的左右子树高度相等，但内部某个结点不平衡的树，确认不能只检查根的高度差。
