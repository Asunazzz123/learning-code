# 02 递归返回值：结点数、叶子数与高度

分别设计递归算法，求二叉树的结点总数、叶子结点数和高度。

约定：空树高度为 0，只有根结点的树高度为 1；叶子指左右孩子均为空的结点。

## 要求

1. 实现下面三个函数，不使用全局计数器。
2. 对每个函数，用一句话说明返回值的含义。
3. 分别说明空树、叶子、非叶子时如何处理。
4. 思考：这些函数为什么可以不传入当前层数？树高与当前结点深度有什么区别？

## 接口

```cpp
int countNodes(Node *root);
int countLeaves(Node *root);
int treeHeight(Node *root);
```

## 自测

| 树的结构 | 结点数 | 叶子数 | 高度 |
|---|---:|---:|---:|
| 空树 | 0 | 0 | 0 |
| 只有根结点 | 1 | 1 | 1 |
| 根结点只有一个右孩子 | 2 | 1 | 2 |
| 根结点有两个孩子，且孩子均为叶子 | 3 | 2 | 2 |

另构造一棵有 4 个结点的左单支树进行测试。
