# 03 递归参数：指定层结点与叶子深度

约定根结点位于第 1 层，当前结点的深度等于其层数。

## 任务 A：输出指定层

实现 `printLevel(root, k)`，从左到右输出第 k 层的所有结点。若树为空、k 小于 1，或不存在第 k 层，则不输出任何结点。

- 必须使用递归，不使用队列。
- 已到达第 k 层后，不再访问这些结点的孩子。
- 可以自行设计辅助函数的参数。

## 任务 B：输出叶子及其深度

实现 `printLeafDepths(root)`，从左到右输出所有叶子，每个叶子输出为 `(值, 深度)`。

例如：

```text
        1
       / \
      2   3
       \
        4
```

- 任务 A，k = 2：`2 3`
- 任务 A，k = 3：`4`
- 任务 B：`(4, 3) (3, 2)`

2. 当前结点的孩子指针能否直接告诉你它处于第几层？
3. 任务 B 中，判断叶子的条件和记录深度的参数分别解决什么问题？
