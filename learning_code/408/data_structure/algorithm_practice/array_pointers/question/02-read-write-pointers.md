# 02 读写双指针：原地压缩有序数组

基础题。

给定非降序数组，原地删除重复元素，使每种值只保留一次。返回新长度 len，仅要求 A[0..len-1] 为结果，其后内容不限。

```cpp
int uniqueSorted(int A[], int n);
```

## 要求

- 时间 O(n)，辅助空间 O(1)。
- 保持结果有序。
- 说明读指针、写指针分别指向什么，以及为什么写入不会覆盖尚未读取的数据。
- 不使用辅助数组或库函数 unique。

## 自测

- [] → len=0。
- [2,2,2] → len=1，前缀 [2]。
- [1,1,2,2,3] → len=3，前缀 [1,2,3]。
- [-3,-1,0,4] → len=4，前缀不变。

## 加练

改为每个值最多保留两次。例如 [1,1,1,2,2,3] 应得到前缀 [1,1,2,2,3]。
