# 01 相向双指针：数组循环移动

关联方法：2010 年真题；基础题。

将长度为 n 的整型数组循环左移 p 位。本练习扩展为允许 n=0、p≥0；n>0 时按 p 对 n 取余后的位数移动。

```cpp
void rotateLeft(int A[], int n, int p);
```

## 要求

- 时间 O(n)，辅助空间 O(1)。
- 自行实现区间逆置函数，采用相向双指针。
- 不使用额外数组，不逐次搬移整个数组。
- 空数组时不能计算 p % n。
- 用两段序列的拼接关系说明正确性。

## 自测

- [1,2,3,4,5]，p=2 → [3,4,5,1,2]。
- [1,2,3,4,5]，p=7 → [3,4,5,1,2]。
- p=0 或 p=n，数组不变。
- 空数组、单元素数组。
