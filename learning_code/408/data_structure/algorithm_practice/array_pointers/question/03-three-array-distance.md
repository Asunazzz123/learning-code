# 03 三个有序数组：最小三元组距离

关联方法：2020 年真题；进阶题。

三个非空、非降序整型数组 A、B、C，分别取 a、b、c，求 D=|a-b|+|b-c|+|c-a| 的最小值。允许负数和重复值。

```cpp
long long minTripleDistance(const int A[], int na,
                            const int B[], int nb,
                            const int C[], int nc);
```

## 要求

- 时间 O(na+nb+nc)，辅助空间 O(1)。
- 不枚举全部三元组，不合并或排序数组。
- 先推导距离与三个数最大值、最小值的关系。
- 说明为何可以推进当前最小值的下标，并说明并列最小时如何处理。
- 使用足够宽的类型完成减法与距离计算，避免先以 int 运算后才转换。

## 自测

- A=[-1,0,9]，B=[-25,-10,10,11]，C=[2,9,17,30,41]：答案 2。
- A=[1]，B=[1]，C=[1]：答案 0。
- A=[1,2]，B=[10]，C=[20]：答案 36。
- 自行添加某个数组先耗尽、最小值并列的情况。

## 加练

同时返回任意一组达到最小距离的三个数组下标。
