# 02 长度对齐：两个链表的共享后缀

关联方法：2012 年真题；基础题。

两个无环、带独立头结点的单链表，可能从某个数据结点开始共享后续结点。返回第一个公共数据结点的地址；无公共结点时返回空指针。

```cpp
ListNode *firstCommon(ListNode *head1, ListNode *head2);
```

## 要求

- 时间 O(m+n)，辅助空间 O(1)，不得修改链表。
- 第一版使用长度对齐实现。
- 比较的是结点地址，不能用数据值判断共享。
- 解释为什么无环单链表一旦相交，后面的结点也相同。

## 自测

- 第一条为 1 → 2 → [7 → 8]，第二条为 3 → [7 → 8]；方括号表示同一批结点：返回共享的 7。
- 两条独立分配、数据均为 1 → 2 的链表：返回空指针。
- 两条链表首个数据结点就相同：返回该结点。
- 一条为空，或两条都为空：返回空指针。

## 加练

尝试用两个指针分别走完两条链表的方式完成，不预先统计长度，并解释其终止性。
