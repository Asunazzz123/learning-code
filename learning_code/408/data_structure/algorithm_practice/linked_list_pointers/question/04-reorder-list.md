# 04 综合：拆分、逆置与交错合并

关联方法：2019 年真题；综合题。

将带头结点的链表 a1 → a2 → … → an 改为 a1 → an → a2 → a(n-1) → …。

```cpp
void reorderList(ListNode *head);
```

## 要求

- 时间 O(n)，辅助空间 O(1)。
- 原地修改链接，不交换数据，不创建或删除数据结点。
- 分成三个可解释的步骤：寻找分界、后半段逆置、两段交替合并。
- 说明奇数长度时中间结点归哪一段。
- 合并前断开两段，避免尾部形成环。

## 自测

| 原序列 | 目标序列 |
|---|---|
| 空 | 空 |
| 1 | 1 |
| 1 → 2 | 1 → 2 |
| 1 → 2 → 3 → 4 | 1 → 4 → 2 → 3 |
| 1 → 2 → 3 → 4 → 5 | 1 → 5 → 2 → 4 → 3 |

验证所有原结点恰好出现一次，且最后结点的 next 为空。
