# 03 三指针：原地逆置单链表

基础题；为链表重排准备。

将带头结点的单链表原地逆置，头结点地址不变，不交换数据，不创建或删除数据结点。

```cpp
void reverseList(ListNode *head);
```

## 要求

- 时间 O(n)，辅助空间 O(1)，使用迭代。
- 为前驱、当前结点和暂存后继分别指定变量。
- 每次修改 next 前，说明哪些尚未处理的结点必须仍然可达。
- 循环结束后正确更新头结点的 next。

## 自测

- 空链表逆置后仍为空。
- 1 逆置后为 1。
- 1 → 2 → 3 → 4 逆置后为 4 → 3 → 2 → 1。
- 连续逆置两次，所有结点的顺序与地址恢复原状。
