# 01 二分边界：查找第一个不小于 x 的元素

基础题。

给定非降序数组 A，返回第一个满足 A[i]≥x 的下标；若不存在，返回 n。

```cpp
int lowerBound(const int A[], int n, int x);
```

## 要求

- 时间 O(log(n+1))，辅助空间 O(1)，不用库函数。
- 任选闭区间或左闭右开区间，全文保持一致。
- 写出循环不变量，解释边界更新为何不会遗漏答案，循环为何终止。
- 允许数组为空、重复值、x 在所有值之外。

## 自测

A=[1,2,2,2,5]：x=2 返回 1；x=3 返回 4；x=6 返回 5。空数组返回 0。

## 加练

实现第一个大于 x 的位置，并用两次边界查找计算 x 的出现次数。不能用 x+1 规避边界，以免整数溢出。
