# 02 两个等长有序数组的中位数

关联方法：2011 年真题；进阶题。

A、B 均为长度 n≥1 的非降序数组。求合并后 2n 个元素中第 n 小的值，排名从 1 开始。这是较小的中间项，不取两项平均值。

```cpp
int lowerMedian(const int A[], const int B[], int n);
```

## 要求

- 第一版：不实际合并数组，用顺序扫描在 O(n) 时间、O(1) 辅助空间内完成。
- 第二版：利用有序性，在 O(log(n+1)) 时间、O(1) 辅助空间内完成。
- 第二版必须解释每次排除元素后，目标排名或保留区间为何仍正确。
- 若按两段中位数比较缩减区间，明确区分剩余长度的奇偶。
- 不改变输入，不调用排序函数。

## 自测

- A=[11,13,15,17,19]，B=[2,4,6,8,20]：11。
- A=[1]，B=[9]：1。
- A=[1,2]，B=[3,4]：2。
- A=[1,2,2]，B=[2,2,3]：2。
