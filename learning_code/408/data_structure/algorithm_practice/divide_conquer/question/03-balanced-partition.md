# 03 快速选择：人数均衡且总和差最大

关联方法：2016 年真题；进阶题。

给定 n≥2 个正整数，原地分成两组：第一组占数组前 floor(n/2) 个位置，第二组占其余位置。要求两组元素个数差最小，并在此前提下使两组和的绝对差最大。允许输入中存在相同值。

```cpp
long long partitionMaxDifference(int A[], int n);
```

## 要求

- 数组允许重排，组内不要求有序。
- 先说明两组分别应该包含哪些排名的元素。
- 使用迭代的快速选择／划分，平均时间 O(n)，辅助空间 O(1)，不能完整排序。
- 返回最终两组总和的绝对差，用 long long 累加。
- 说明最坏时间复杂度，以及相同值很多时如何保证区间继续缩小。

## 自测

- [1,2,3,4]：和差 4。
- [1,2,3,4,5]：和差 9，较小组有 2 个元素。
- [2,2,2,2]：和差 0。
- [2,2,2]：和差 2。
- 两元素、已升序、已降序输入。

只要两组满足要求，不限制划分后的具体排列。
