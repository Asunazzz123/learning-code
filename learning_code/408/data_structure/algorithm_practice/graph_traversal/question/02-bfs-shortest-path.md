# 02 BFS：无权图最短路径长度

基础题。

给定邻接矩阵存储的无向简单图以及合法顶点 s、t。返回 s 到 t 的最少边数；不可达返回 -1，s=t 时返回 0。

```cpp
int shortestDistance(const MGraph &G, int s, int t);
```

## 要求

- 使用 BFS，时间 O(V²)，辅助空间 O(V)。
- 可以使用标准队列，也可以自行实现容量足够的队列。
- 用距离数组兼任访问标记。
- 说明为何在入队时设置距离，而不是出队时才标记。
- 解释第一次发现目标时为什么已经得到最短距离。

## 自测

顶点 0..5，边为 0—1、1—2、2—3、0—4、4—3，5 孤立：

- s=0，t=3：2。
- s=0，t=5：-1。
- s=2，t=2：0。

## 加练

增加前驱数组，输出任意一条最短路径。若有多条，不要求固定选择哪一条。
