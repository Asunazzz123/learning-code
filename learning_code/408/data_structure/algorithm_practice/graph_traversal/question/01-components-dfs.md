# 01 DFS：统计无向图连通分量

基础题。

给定邻接矩阵存储的无向简单图，返回连通分量数。孤立顶点单独构成一个分量，n=0 时返回 0。

```cpp
int countComponents(const MGraph &G);
```

## 要求

- 使用递归 DFS，时间 O(V²)，辅助空间 O(V)。
- visited 在外层统一初始化，所有 DFS 调用共享它，不使用全局变量。
- 解释外层为何还需枚举所有顶点。
- 解释为什么访问标记应在递归访问邻接点之前设置。
- 复杂度必须计入递归栈。

## 自测

- 顶点 0..4，边为 0—1、1—2、3—4：2。
- 三个孤立顶点：3。
- 三角形：1，且递归能够终止。
- 空图：0。

## 加练

改用邻接表描述同样算法，比较复杂度；不要求实现两套存储。
