# 03 DFS 与回溯：枚举指定长度的简单路径

进阶题。

给定邻接矩阵存储的有向简单图，枚举从合法顶点 s 出发、恰好包含 k 条边的所有简单路径。简单路径中顶点不能重复，规定 0≤k<V。

```cpp
void printSimplePaths(const MGraph &G, int s, int k);
```

## 要求

- 每条路径输出一行顶点编号，相邻编号用空格分隔。
- 邻接点按编号递增尝试，输出顺序由此确定。
- k=0 时只输出 s；无满足条件的路径时不输出。
- 使用路径数组与当前路径访问标记，不使用全局变量。
- 明确递归参数表示“已走边数”还是“剩余边数”。
- 解释回溯时为何必须撤销标记，以及这与普通可达性 DFS 的区别。
- 给出辅助空间上界，并解释输出规模可能随 k 急剧增长，不能套用普通 DFS 的 O(V²) 总时间结论。

## 自测

边为 0→1、0→2、1→2、2→1、1→3、2→3，s=0，k=2：

```text
0 1 2
0 1 3
0 2 1
0 2 3
```

补充带有回到 s 的边的情况，确认不会重复经过 s。
