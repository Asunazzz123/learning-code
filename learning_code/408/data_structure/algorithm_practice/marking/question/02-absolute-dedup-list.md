# 02 标记与删除：链表按绝对值去重

关联方法：2015 年真题；组合题。

带头结点链表有 m 个数据结点，结点值满足 -M≤data≤M，M≥0。对绝对值相同的结点，仅保留第一次出现者，删除并释放其余结点。

```cpp
void removeAbsDuplicates(ListNode *head, int M);
```

## 要求

- 时间 O(m+M)，辅助空间 O(M+1)；初始化时间必须计入。
- 使用标记数组和前驱指针，不使用集合或哈希容器。
- 删除结点后正确继续扫描，不能访问已释放结点。
- 保留结点的原始符号和相对顺序。
- 说明为什么需要为绝对值 0 留一个标记位置。

## 自测

- 1 → -1 → 2 → -2 → 0 → 0 → -3，M=3：结果 1 → 2 → 0 → -3。
- -2 → 2 → -2，M=2：结果 -2。
- 空链表；全是 0 的链表；没有重复绝对值的链表。

结点假定通过 new 创建，用 delete 释放；不能仅跳过结点而泄漏其存储。
