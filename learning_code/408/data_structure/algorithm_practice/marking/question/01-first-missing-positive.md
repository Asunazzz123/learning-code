# 01 出现标记：最小缺失正整数

关联方法：2018 年真题；基础题。

给定长度为 n≥0 的无序整型数组，求其中未出现的最小正整数，不改变原数组。

```cpp
int firstMissingPositive(const int A[], int n);
```

## 要求

- 时间 O(n)，辅助空间 O(n)；n=0 时返回 1。
- 先证明答案为何不超过 n+1，再确定标记数组范围。
- 说明负数、零、重复值、大于 n 的值如何处理。
- 不排序，不反复扫描原数组查找每个候选值。

## 自测

[-2,7,8] → 1；[1,2,3] → 4；[3,1,1] → 2；[] → 1。

seen[x] 表示值 x 出现过，还是原数组第 x 个位置已经访问过？为什么两者不能混淆？
