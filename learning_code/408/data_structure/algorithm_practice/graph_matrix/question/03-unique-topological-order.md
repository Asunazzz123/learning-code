# 03 零入度消减：唯一拓扑序

关联方法：2024 年真题；综合题。

给定 n≥1 的有向简单图，不保证无环。若恰好存在一个包含全部顶点的拓扑序列，返回 true，否则返回 false。

```cpp
bool hasUniqueTopologicalOrder(const MGraph &G);
```

## 要求

- 时间 O(V²)，辅助空间 O(V)，不修改输入矩阵。
- 自行维护剩余入度和顶点是否已处理的信息。
- 分别说明当前可选零入度顶点为 0 个、1 个、多个时的含义。
- 已处理顶点不能因为入度为 0 而被再次选择。
- 若已发现多个候选，可以立即判定不满足“恰好一个拓扑序”，无需继续区分是否有环。

## 自测

- 0→1→2：true。
- 0→2、1→2：false。
- 0→1、1→0：false。
- 单个孤立顶点：true。
- 两个孤立顶点：false。
- 0→1，另有 2→3、3→2：false。

## 思考

“本轮按照最小编号选一个零入度点”得到确定的输出，能否证明拓扑序唯一？
