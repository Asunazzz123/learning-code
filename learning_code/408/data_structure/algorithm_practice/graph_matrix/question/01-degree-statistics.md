# 01 行列扫描：入度、出度与 K 顶点

关联方法：2023 年真题；基础题。

给定邻接矩阵表示的有向简单图。输出所有出度大于入度的顶点编号，按编号递增，并返回数量。

```cpp
int printKVertices(const MGraph &G);
```

## 要求

- 时间 O(V²)，辅助空间 O(1)，不修改图。
- 解释第 i 行、第 i 列各自代表什么。
- 不使用 DFS/BFS；本题只需要统计边。
- 允许无边图、孤立顶点和 n=0。

## 自测

顶点 0、1、2、3，边为 0→1、0→2、2→1，顶点 3 孤立：输出 0 2，返回 2。

只有 0→1、1→2、2→0 的三点有向环：无输出，返回 0。

## 加练

按编号递增输出入度为 0 的顶点，再输出出度为 0 的顶点。孤立顶点是否会出现在两组里？
