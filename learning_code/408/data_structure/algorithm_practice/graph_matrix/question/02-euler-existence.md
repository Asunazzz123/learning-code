# 02 无向图：EL 路径存在性

关联方法：2021 年真题；基础与扩展题。

本题的 EL 路径允许重复经过顶点，但每条边恰好经过一次；起终点允许相同。

## 任务 A：已知连通

给定至少有一条边的无向连通简单图，判断是否存在 EL 路径。

```cpp
bool hasEulerTrailConnected(const MGraph &G);
```

- 时间 O(V²)，辅助空间 O(1)。
- 不必构造路径，也不必重复检查题目已保证的连通性。
- 写清度数判据，区分路径与回路。

## 任务 B：不保证连通

取消连通保证，仍至少有一条边。实现 hasEulerTrailGeneral，除度数外，加入必要的连通性检查；允许 O(V) 辅助空间。

- 判断哪些顶点需要处于同一连通分量。
- 说明孤立顶点是否妨碍遍历所有边。

## 自测

- 三点链 0—1—2：存在。
- 三角形：存在。
- 中心连接三个叶子的星形：不存在。
- 两个互不相连的三角形：任务 B 返回 false。
- 一个三角形加一个孤立顶点：任务 B 返回 true。

本题无需输出具体 EL 路径。
